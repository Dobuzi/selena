배틀 규칙 · 데이터 (3/4)

솔로 / 멀티 공통 문제 포맷 + 판정 규칙

배틀 공통 규칙

한 판 = 10문항 · 문항당 제한 시간
  • 문항 수: 10 (MVP 고정)
  • 문항당 시간: 20초 (시간 초과 = 오답)
  • 형식: 4지선다 객관식
  • 과목: 국어 / 영어 / 수학 / 과학 · 난이도: 하 / 중 / 상
  • 정답 공개 시점: 제출 직후 (해설 1~2문장, AI 생성)
솔로 — vs AI

HP: 나 3 · AI 3

정답 → AI HP −1 (공격 성공)

오답/시간초과 → 내 HP −1

승리: AI HP 0 또는 10문항 후 HP 더 많음

패배: 내 HP 0

AI는 “상대 체력 바”일 뿐, 별도 문제 풀이 없음

멀티 — 같은 시험장

인원: 2~4명 (MVP)

진행: 호스트가 시작 → 전원 같은 문항·타이머

점수: 정답 +100, 남은 시간 보너스 +남은초×2

오답/시간초과: +0

순위: 10문항 후 총점 높은 순

방 ID 규칙

입력값 trim → 소문자/공백 정규화 → school|examHall|subject 조합 해시.
같은 학교·시험장·과목이면 같은 방. 난이도는 방 생성 시 고정 (먼저 만든 사람 기준).
