에러 처리 · 테스트 · MVP 범위 (4/4)

실패해도 “게임이 멈춘 것처럼” 보이지 않게

주요 실패 시나리오

1

AI 문제 생성 실패

재시도 1회 → 실패 시 과목별 폴백 문제 세트(내장 샘플) 사용. 유저에게 “연습 문제로 진행” 안내.

2

잘못된 AI JSON / 정답 누락

스키마 검증 후 불량 문항 폐기·재생성. 10문항 채우지 못하면 폴백으로 보충.

3

멀티 연결 끊김

짧은 재연결 시도. 복구 실패 시 해당 플레이어 기권 처리, 나머지는 계속.

4

빈 방 / 중복 닉네임

학교·시험장 필수 입력. 닉네임 중복 시 접미사 자동 부여 (예: 민수_2).

테스트 (MVP)
  • 방 ID 정규화 단위 테스트
  • 배틀 점수·HP 판정 단위 테스트
  • 문제 JSON 스키마 검증 테스트
  • 솔로 플로우 통합(폴백 문제)
  • 멀티: 2인 시작·제출·순위 (가능 범위)
MVP in / out

In

방 만들기·입장, AI/폴백 문제, 솔로 배틀, 간단 멀티, 결과 화면

Out

로그인, 랭킹 DB, 오답 노트, 캐릭터 육성, 모바일 앱, 관리자 출제 도구
